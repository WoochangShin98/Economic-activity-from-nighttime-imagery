Estimating County-Level Poverty Rates from Nighttime Satellite Imagery

Machine Learning and Deep Learning for County-Level Socioeconomic Estimation

Mainland United States · 2024 VIIRS · TIGER/Line · SAIPE

Woochang Shin Jisun Kim le000531 huangshihwen51-prog
GitHub Repository Results Models

Abstract

This project investigates whether nighttime satellite imagery can be used to predict county-level poverty rates across the mainland United States. We combine 2024 VIIRS nighttime-light imagery, TIGER/Line county polygons, and 2024 SAIPE county-level poverty estimates, and formulate the task as a continuous regression problem.

We compare handcrafted brightness-based statistical models, an end-to-end CNN, and hybrid models that extract CNN embeddings and use classical regression algorithms.

The strongest model is an improved Random Forest regressor trained on CNN embeddings, achieving an R² of 0.141.

Data

The project uses three main data sources:

  • 2024 VIIRS nighttime-light imagery for nighttime illumination patterns.
  • TIGER/Line county polygons for county-level geographic boundaries.
  • 2024 SAIPE county-level poverty rates as the prediction target.

Compared with the original proposal focused on GDP-tier classification, the task was reformulated as a continuous county-level poverty-rate regression problem.

Approach

Model 1 — Statistical Brightness Regression

We first construct handcrafted nighttime-light brightness features and evaluate traditional regression methods including Linear Regression and Random Forest Regression.

This baseline measures how much socioeconomic information can be captured through aggregate brightness statistics alone.

Model 2 — CNN Hybrid Embedding Regression

County-level nighttime images are passed through a CNN feature extractor. The resulting feature embeddings are then used as inputs to regression models.

The pipeline is:

County Image → CNN Feature Extractor → Embedding Extraction → Regression Model

We evaluate both Ridge Regression and Random Forest Regression on the learned CNN embeddings.

Model 3 — Improved Hybrid CNN Embedding Regression

The improved pipeline introduces preprocessing and modeling changes designed to make county-level nighttime-light representations more stable and informative.

  • Logarithmic brightness transformation using log1p
  • Grayscale background compositing
  • Illumination normalization
  • Proportional county scaling
  • Border-aware preprocessing
  • Tuned Random Forest regression
  • Improved CNN embedding stability

Best-Performing Model

The best-performing model is Random Forest Regression on improved CNN embeddings, with an R² of 0.141.

Main Findings

  • CNN embedding hybrid models outperform handcrafted statistical baselines.
  • End-to-end CNN regression performs worse than hybrid embedding-based models.
  • Spatial nighttime-light patterns contain socioeconomic information beyond simple brightness statistics.
  • Improved preprocessing and hybrid embedding regression produce the strongest predictive performance.
  • The results suggest that nighttime-light imagery contains a measurable, though limited, signal related to county-level poverty.

Limitations and Future Work

Although the improved hybrid model performs best among the evaluated approaches, the overall R² remains modest.

Poverty is influenced by many factors that cannot be fully captured through nighttime illumination alone, including housing costs, demographic structure, employment, access to services, and regional economic differences.

Future work could combine nighttime-light imagery with additional spatial and socioeconomic variables, investigate stronger pretrained vision encoders, test alternative spatial aggregation strategies, and evaluate model generalization across different years and regions.
